# 伴学反馈记录与提报

如实采集 `study` 伴学过程中的现场运行轨迹与原始失真切片，生成保留结构细节的记录单并按需外发。仅在用户显式输入 `/study-feedback` 时启动；未显式输入该命令的新会话或日常追问一律不调用本技能。

## 现场采集规程

**终点**：已回扫当前伴学会话并生成客观四要素现场记录单，全程不读取也不改动 `study` 规程正文，不替下游预设规程定性或改法；按 `gh` 探测结果与用户选择完成提交或保留代码块后收口结束。

- **回扫现场**：附有口头说明时结合上下文定位对应伴学环节；零打字调用时自动回扫当前会话，定位用户纠偏、喊停、嫌分卡过碎过粗、嫌探针跑偏或反复追问才搞通的位置。长会话存在多处明显卡顿且定位不唯一时，先用一句列出候选现场请用户点选确认，不自行脑补原因。空白会话且无伴学上下文时，如实告知无可提取记录，不编造条目。
- **纯现场客观采集**：只充当高保真行车记录仪，记录四项客观事实——`运行轨迹`记明模型思考档位、模式深度、已读子文件或脚本、探针结果与卡号轮次；`用户原话与卡点`原样摘录追问与受阻处；`期望体验`从学习视角说明理想顺推或画面，不预设改哪条规则；`原始失真切片`原样摘录标题骨架、推导段、脚本报错或交互题原文，严禁将多行原文压缩改写成笼统摘要。
- **保真洗净与外发收口**：出单前不另加前置询问，直接按默认保真与洗净规则出单；公开教材、公开论文、开源库与通用数理算式直接保留真实公式与原文切片；自动洗净本地盘符与用户名路径，仅当涉及未发表专有代码或商业保密数据时对专有名称和私有常数做一对一等构替换，不改写数学结构与推导原文。未经用户明确同意不得静默外发：
  1. **先出单**：将下方四要素记录单包在 ` `````markdown ` 代码块内输出，提醒用户核对切片未含涉密业务代号或未发表专有参数。
  2. **只读探测**：静默运行 `python "<本技能目录>/scripts/submit_feedback.py" --probe` 探测 `gh` 安装与登录状态；无系统 Python 时改用 `python3` 或 `uv run --no-project ...` 兜底。
  3. **用户选路**：推荐将邮箱项放首位，简要说明点选或直接回复序号即可发送、免登录免配置。`gh` 可用且已登录时三选一：① 推送到维护者邮箱（推荐）；② 一键提交到 `crrisugi/study-skill` GitHub Issue；③ 仅保留当前代码块。否则二选一：① 推送到维护者邮箱（推荐）；② 仅保留代码块并附 `https://github.com/crrisugi/study-skill/issues/new` 供手动提交。
  4. **通道执行**：经用户同意后，将外发记录单写入系统临时文件，运行 `python "<本技能目录>/scripts/submit_feedback.py" --channel github|email --title "<一句话问题标题>" --body-file "<临时文件路径>" --delete-body-file`；无系统 Python 时改用 `python3` 或 `uv run --no-project` 兜底，成功告知结果或链接，环境缺失或外发失败时保留代码块兜底。

- **期望体验**：`<学习视角下期望呈现的讲解顺序、画面或交互效果，不预设规程改动>`
- **原始失真切片**：

- **版本提示**：仅在同级存在 `study` 技能目录时，结束前顺带运行 `python "<同级study目录>/scripts/check_update.py" --notify`，无系统 Python 时改用 `python3` 或 `uv run --no-project` 兜底；有新版输出则在末尾用一行告知版本号与升级命令，绝不自动覆盖本地文件。
