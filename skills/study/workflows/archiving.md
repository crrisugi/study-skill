# 伴学落盘细则与产出文档模板

由主干 [SKILL.md](../SKILL.md) 在写目录模式下写入 `00_伴学脉络蓝图.md` 或整理笔记文件时按需加载。

---

## 一、落盘整理与验收细则

- **沿用对话顺推底稿**：落盘笔记面向日后脱离原件独立阅读，直接以对话里已讲顺的推演主体为底稿做轻整理，保留关键展开式、变形目的以及对话中用到的极简小例、对照与配图，不压缩成空洞提纲，也不把同一例子拆成两处重复写；对话未举算例的卡绝不临时补编。
- **剥离互动并揉顺追问**：删去开局路线预览、前置探针问答、寒暄试错及卡末停顿确认等对话互动痕迹；将对话中途的追问解释、顺手补讲的新符号或轻铺垫以及卡壳后换路讲通的直白小例自然揉进对应小节，删去前面迂回旧讲法，成段铺垫保留小标题与主推导隔开，答对稳固的上游底座写出承接起点式保持独立可读。
- **速通短卡与直答单篇**：非标“核心”的 `直觉速通` 卡存 `卡XX_[概念名称].md`，用自然 `##` 小标题简写出发点、核心机制与直观成因，省去繁琐分步变形，保留末尾结论前提框。靶向直答后临时要求存盘时，确认目录后存为独立单篇 `[概念名称].md`，不编卡号、不建蓝图。
- **配图入库与纯净引用**：确认归档时，才将临时区配图存入目标目录 `assets/卡XX_图名.<后缀>` 或直答单篇 `assets/[概念名称]_图名.<后缀>`；正文统一改为相对路径 `` `![图注](assets/...)` ``，不写入 `<agent-embed>`，也不在对话框重复贴整卡正文。
- **同步蓝图主线记录**：已有蓝图时，每张卡片完成后按完成次序往 `00_伴学脉络蓝图.md` 的 `## 三、已学主线与阶段收获` 追加 `1` 条简明记录，点明承接节点、演进性质与核心收获；先修短卡采用缩进列表项，后续正卡顶格紧随其后；跳过存盘的卡句末括注 `（未落盘）`；末卡结课末尾补写收官核心式与总前提。
- **落盘校验**：带图单卡或带图直答单篇落盘后跑单文件体检，写目录分卡伴学末卡结课前跑整目录验收，优先用 `python` 或 `python3` 运行 `"<本技能目录>/scripts/check_notes.py" "<目标路径>"`，无系统 Python 时改用 `uv run --no-project "<本技能目录>/scripts/check_notes.py" "<目标路径>"` 兜底，修完报错再宣布归档或结课；纯文字中间卡免跑。若终端输出含 `[study] 发现新版`，在结课末尾附一行升级提示，同会话至多一次。

## 产出文档模板

### 1. 开局脉络文件模板（`00_伴学脉络蓝图.md`）

```markdown
# 00｜学习脉络：[用一句平实人话概括这份材料要搞懂什么]

> **学习材料**：[原图/论文/代码文件名或链接] ｜ **默认深度**：[直觉速通 / 标准推演 / 深度精读]

## 一、这次学什么、哪些底层前提先直接拿来用
- **核心问题**：（用两三句简明书面语说清这份材料整体在解决什么表达、建模、算法或选型问题）
- **先直接拿来用的前提**：（对原材料未展开的底层推导或外部模块，每项用一句简明书面语交代“输入条件与输出结果”，正文直接当已知底座用）

## 二、卡片学习顺序（共 X 张；同卡拆多机制用 01.1 / 01.2，卡前先修用 01_0.1 / 02_0.1）
| 顺序 | 卡片主题（括注原位置或“先修铺垫”；关键推导卡括注“核心”） | 这一步主要搞懂什么 |
| :--- | :--- | :--- |
| 卡 01 | ... | （用一句简明书面语说清承接哪个上游节点、推进或分叉解决什么问题） |
| 卡 02 | ... | ... |

## 三、已学主线与阶段收获
（开局暂留空，按上文主线记录规则逐卡追加；仅多份材料混读且符号不统一时，另附 `## 四、跨文档符号对照表`。）
```

### 2. 单张学习笔记卡骨架示例（`卡XX_[概念名称].md`）

直接沿用对话小标题或按本卡内容使用直白的自然 `##` 小标题，小节数量按需增减，绝不照抄方括号占位说明，也不套带【】的列表外壳；框外补充项按主干收尾规则仅在确有增量时附后：

```markdown
# 卡 XX｜[概念名称]（原位置：xxx；先修卡写“先修铺垫”）

## 出发点：[概括老办法卡在哪或本卡要解决什么问题]
（两三句清朗短陈述句说清问题起点与核心对象；需用到的核心算式或关键代码居中写全）

## [按推演阶段、模块或边界对比命名的直白动宾短句]
（沿用对话讲顺的推演底稿，大公式、表与配图紧贴对应段落下方；按内容续排后续小节）

---

> **核心结论**：[剥去过程铺垫与前提从句，直写定型结果与规律]
>
> **成立前提**：[只写破坏后结论失效的物理与数学硬条件]
```
