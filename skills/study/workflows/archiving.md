# 伴学落盘细则与产出文档模板

由主干 [SKILL.md](../SKILL.md) 在写入 `00_伴学脉络蓝图.md` 或确认单卡落盘、合并总卡时按需加载；纯会话伴读与常规对话推演不读本文件。

---

## 一、落盘与验收细则

- **合并慢嚼卡**：对话时分 `k-A / k-B` 两小步慢嚼的复杂卡片，落盘时合并为同一张完整笔记卡，靠分步打括号或分段理清层次。
- **速通落盘形态**：单块材料 `直觉速通` 合并写 `01_全篇脉络总卡.md` 时，顺着卡片串起核心结论、小算例和配图，权衡和适用条件留到总卡末尾统一写一次；总图 `直觉速通` 分节短卡按 [long-corpus.md](long-corpus.md) 精简三块结构逐卡落盘。
- **配图与正文纯净**：笔记内配图统一写相对路径 `![图注](assets/卡XX_图名.<后缀>)`，不把 `<agent-embed>` 写入 `.md`，也不在对话框重复贴整卡正文。
- **落盘校验**：带图单卡落盘后跑单文件体检，写工作区文件且末卡结课前跑整目录验收，执行 `python "<本技能目录>/scripts/check_notes.py" "<目标路径>"`；无系统 Python 时改用 `uv run --project "<本技能目录>/scripts" python ...` 兜底，修完报错再宣布归档或结课；纯文字中间卡与纯会话伴读免跑。

## 产出文档模板

### 1. 开局脉络文件模板（`00_伴学脉络蓝图.md`）

```markdown
# 00｜学习脉络：[用一句平实人话概括这份材料要搞懂什么]

> **学习材料**：[原图/论文/代码文件名或链接] ｜ **默认深度**：[直觉速通 / 标准推演 / 深度精读]

## 一、这次学什么、哪些底层前提先直接拿来用
- **核心问题**：（用两三句大白话说清这份材料整体在解决什么表达、建模、算法或选型问题）
- **先直接拿来用的前提**：（对原材料未展开的底层推导或外部模块，每项只用一句大白话交代“它输入什么、给我们什么结果”，正文直接当已知底座用）

## 二、卡片学习顺序（从简到繁共 X 张；同卡拆多机制用 01.1 / 01.2，卡前先修用 目标卡号_0.1 / _0.2）
| 顺序 | 卡片主题（括注原位置或“先修铺垫”；核心推导卡括注“核心”） | 这一步主要搞懂什么 |
| :--- | :--- | :--- |
| 卡 01 | ... | （用一句平实白话说清这一张卡解决什么问题、比上一张多了什么） |
| 卡 02 | ... | ... |

## 三、底座算例设定
- **最小输入与范围设定**：（连贯推导列全篇共用的一套最小输入，并列独立主题按组或按卡各自列；多源对照材料可在此附简短的《跨文档符号/变量对照表》）
- **代入的具体数值**：（写明各卡用来算账对比的具体小整数、简单基函数或初始状态）
```

### 2. 单张学习笔记卡模板（`卡XX_[概念名称].md`）

```markdown
# 卡 XX｜[概念名称]（原位置：xxx；先修卡写“先修铺垫”）

- **【问题起点】**：（写明本卡要解决的核心问题；若有直白的已学老办法或关键辅助结构，写清照旧算到哪步卡住或删掉它会漏掉什么重叠、耦合或边界）
- **【最小模型与直白推演】**：（用平实短陈述句借对应表征的最小模型顺推；数值小表与 `![图注](assets/卡XX_图名.<后缀>)` 紧贴首次看图段下方嵌入；**核心结论加粗**）
- **【原式/原逻辑拆解与小算例对账】**：
  - 核心表达 / 分步拆解（算式写全 `左端目标量 =/≈ 右端表达式`，代码或证明写清核心分支与前提依赖）：
  - 最小模型闭合验算 / 正反例核对（代入底座算例算到具体得数或状态跃迁；纯定理证明验最小正例与去前提反例）：
  - 量纲 / 消元 / 维度或状态对账链：（按对象择一写清物理量纲、积分求和消元、张量 `Shape`、控制体/状态流转、前提蕴含、紧松乘子或误差稳定域对账）
- **【决策权衡】**：（算法/工程卡写清换来什么实在好处，付出什么计算、内存或结构代价；公式推导卡写清这步变形化简了什么麻烦，如解耦、降维、去积分号，同时多背了什么求导阶数、附加约束或范围代价）
- **【适用边界与常见误区】**：（紧扣本卡算例与原文范围写成立前提与易混处，有 `1` 条写 `1` 条，不剧透下卡；依当前深度档位取舍原书旁支与退化反例）
```
