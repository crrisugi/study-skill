# 伴学落盘细则与产出文档模板

由主干 [SKILL.md](../SKILL.md) 在写入 `00_伴学脉络蓝图.md` 或确认单卡落盘时按需加载；常规对话推演不读本文件；纯会话伴读仅按需参看蓝图结构，不写工作区也不跑校验。

---

## 一、落盘与验收细则

- **沿用对话顺推底稿**：落盘笔记面向日后独立阅读，直接以对话里已讲顺的推演为底稿做轻整理，保留关键展开式、变形目的以及对话中用到的直觉工具、对照与配图，不压缩成空洞提纲，也不把同一例子拆成两处重复写。
- **剥离对话互动痕迹**：删去路线表、顶部主线回放、摸底与免摸底过程、试错与寒暄语及各类停顿确认等对话互动痕迹；仅把追问或补讲得出的有启发结论无痕融进正文或易混处。
- **揉顺追问与补讲**：将对话中途的追问解释与卡壳后换路讲通的直白小例子自然揉进对应小节，不写成一问一答聊天体，删去前面迂回的旧讲法；正文里并列相似长式的结构锚定照常保留，确保日后独立重读不看串。
- **摸底成果无痕融入**：对话中顺手补讲的新符号画面、轻铺垫及出场已结合推导拆透的易混误区，直接自然留在对应小节，末尾易混边界不再重复；成段补讲前置时保留 `前置铺垫：…` 类自然小标题与主推导隔开，均不提因摸底补讲。仅正文未展开或跨约定反号的易混点收进结尾易混边界；答对跳过的基础靠正文用到时写清关键算式保持独立可读。
- **顺手自查不漏项**：沿用风格卡的讲义排版，不改写成带【】的提纲列表。落盘前按需核对五项：问题起点、顺推与关键直觉、量纲或维度核对、结论与前提、得失与易混边界；对话未举算例的卡绝不临时补编，仅漏写核对句时顺手补入。
- **速通轻量短卡**：`直觉速通` 逐卡存 `卡XX_[概念名称].md`，保留 `# 卡 XX｜[概念名称]（原位置：xxx）` 标题，正文用 `2~3` 个自然 `##` 小标题简写出发点、核心结论与直观成因，小例、对照与配图按需保留，省去繁琐分步变形，末尾保留分割线后的结论、前提与按需边界。
- **直答独立存篇**：靶向直答后用户临时要求存笔记时，确认目标目录后直接按自然讲义结构存为独立单篇 `[概念名称].md`，配图存入同级 `assets/[概念名称]_图名.<后缀>`，不编 `卡XX` 号、不建蓝图，带图时跑单文件 `check_notes.py` 校验即可。
- **配图入库与纯净**：确认本卡落盘时，才将临时区配图存入笔记目录 `assets/卡XX_图名.<后缀>`；正文统一写相对路径 `![图注](assets/卡XX_图名.<后缀>)`，不写入 `<agent-embed>`，也不在对话框重复贴整卡正文。
- **同步蓝图主线记录**：已有蓝图时，每张正卡完成同轮，往 `00_伴学脉络蓝图.md` 的 `## 三、已学主线与阶段收获` 末尾追加 `1` 条 `1~2` 句通顺平实短句，点明承接哪个上游算式或节点、属于哪类演进如新增近似推进、同级等价改写、回退母式代特例或另开支线，以及本步核心收获，确有未完缺口时再写留待后续的问题；未落盘该卡时句末括注 `（未落盘）`。先修铺垫卡缩进挂在对应正卡前，用 `1` 句短话说清补了什么工具、给哪一步铺路。末卡结课末尾补 `2` 行整单元收官核心式与总前提。
- **落盘校验**：带图单卡落盘后跑单文件体检，写工作区文件且末卡结课前跑整目录验收，执行 `python "<本技能目录>/scripts/check_notes.py" "<目标路径>"`；无系统 Python 时改用 `uv run --project "<本技能目录>/scripts" python ...` 兜底，修完报错再宣布归档或结课；纯文字中间卡与纯会话伴读免跑。续接老目录或需一键回看已学主线时，可运行 `python "<本技能目录>/scripts/check_notes.py" --recap "<笔记目录>"`，优先输出蓝图第三节，缺节时自动抓取已归档卡片核心结论兜底。

## 产出文档模板

### 1. 开局脉络文件模板（`00_伴学脉络蓝图.md`）

```markdown
# 00｜学习脉络：[用一句平实人话概括这份材料要搞懂什么]

> **学习材料**：[原图/论文/代码文件名或链接] ｜ **默认深度**：[直觉速通 / 标准推演 / 深度精读]

## 一、这次学什么、哪些底层前提先直接拿来用
- **核心问题**：（用两三句简明书面语说清这份材料整体在解决什么表达、建模、算法或选型问题）
- **先直接拿来用的前提**：（对原材料未展开的底层推导或外部模块，每项只用一句简明书面语交代“输入条件与输出结果”，正文直接当已知底座用）

## 二、卡片学习顺序（从简到繁共 X 张；同卡拆多机制用 01.1 / 01.2，卡前先修用 目标卡号_0.1 / _0.2）
| 顺序 | 卡片主题（括注原位置或“先修铺垫”；核心推导卡括注“核心”） | 这一步主要搞懂什么 |
| :--- | :--- | :--- |
| 卡 01 | ... | （用一句简明书面语说清承接哪个上游节点、推进或分叉解决什么问题） |
| 卡 02 | ... | ... |

## 三、已学主线与阶段收获
（开局暂留空，按上文主线记录规则逐卡追加；仅多份材料混读且符号不统一时，另附 `## 四、跨文档符号对照表`。）
```

### 2. 单张学习笔记卡骨架示例（`卡XX_[概念名称].md`）

直接沿用对话小标题或按本卡内容使用路线式 `##` 小标题，小节数量按需增减，绝不照抄方括号占位说明，也不套带【】的列表外壳：

```markdown
# 卡 XX｜[概念名称]（原位置：xxx；先修卡写“先修铺垫”）

## 出发点：[概括老办法卡在哪或本卡要解决什么问题]
（两三句清朗短陈述句说清问题起点与核心对象；需用到的核心算式或关键代码居中写全）

## 步骤 1：[概括本步动作与目标；非推导卡改用 模块 1 / 对比 等]
（沿用对话讲顺的推演底稿，大公式、表与配图紧贴对应段落下方；按内容续排 步骤 2 等）

---

> **核心结论**：[用一两句直白书面短话收束本卡核心结论]
>
> **成立前提**：[写清该结论依赖的硬门槛条件]

- **得失权衡**：[写清这步做法换来的收益与付出的代价，正文已讲透处不复读]
- **易混边界**：[仅补切换约定反号或未展开旁支备注等正文未写重的新边界，有 `1` 条写 `1` 条]
```
