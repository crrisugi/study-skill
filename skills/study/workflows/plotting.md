# 伴学绘图施工与内联展示细则

由主干 [SKILL.md](../SKILL.md) 在需要新画 `.svg` 配图或搬运原件图示时按需加载；常规纯文字推演卡不读本文件。

---

## 一、配图来源与分工

- **原件已有清晰图示**：现成独立图片直接复制一份，不挪动原件；嵌在整页或 PDF 中的清晰图能干净裁出就截取并裁掉图外原书图注行；截不出、太糊，或仅是简单框图与曲线且图内夹杂杂乱旧编号与水印时，照原图意思用 `.svg` 重画。
- **曲线、谱图、热力图与几何矢量**：走 Python `plot_helper.py` 导出瘦身 `.svg`。
- **代码分支、状态跳变、模块时序与维度流向**：直接手写 `<svg>` 并经 `check_svg.py` 过检后展示。

---

## 二、曲线与谱图施工清单

1. **读顶部速查**：只读 `scripts/plot_helper.py` 顶部速查注释；未覆盖新图型直接用返回的原生 `fig, ax` 自由绘制，伴学期间不改公共脚本。
2. **临时脚本与按需出表**：绘图临时 `.py` 写进系统临时目录，不在工作区留脚本。看形状趋势的图直接在图上标清关键点，正文不强制附数值小表；仅当正文确需读准数值做对比时，才在同一脚本里顺手 `print` 出特征点填表，保证表图一致。
3. **运行导出图形**：用 `uv run --project "<本技能目录>/scripts" "<系统临时目录>/plot_xx.py"` 导出瘦身 `.svg`；需内联展示时传 `html_path` 参数一并写入透明底网页，缺 `uv` 时提示用户先装环境。
4. **看终端不看图**：终端打印碰撞、图例或配色提示时调坐标或精简文案重跑，默认不读图检查。

---

## 三、流向与状态图施工清单

1. **规范手写源码**：手写 `<svg>` 须写全 4 数值 `viewBox`，源码首行自带柔和浅底圆角 `<rect>`（如 `#f4f6f8`），配浅色高亮、黑体字与带箭头连线；等价对象保持同线型，虚线只作边界或辅助；图内文字不写裸 LaTeX 源码。
2. **全量跑快检**：所有手写 `<svg>` 画完均跑 `check_svg.py` 过检。优先用 `python` 或 `python3` 运行 `"<本技能目录>/scripts/check_svg.py" "<图路径>"`，无系统 Python 时用 `uv run --project "<本技能目录>/scripts" python ...` 兜底；需内联网页时附加 `--html "<网页路径>"`，未过检按提示修完再展示。

---

## 四、通用图内排版底线

- **原位直标优先**：曲线名、方向箭头与关键数值直接标在线或箭头旁；说明框放空白角不压曲线，少用孤立图例框。
- **配色与符号统一**：单图主色不超 `3` 种，同卡多图同一量固定同色；图内正负号与字母跟正文算式一致。
- **连续失败熔断**：脚本报错或体检碰撞连续修 `2` 次仍未过时立即停手，不再死循环重跑；改拆更简小图、改用具体数表，或把卡点摊开交用户定夺。

---

## 五、存盘落点与跨宿主展示

1. **先存临时区再入库**：讲卡展示、靶向直答与纯会话伴读期间，新画 `.svg` 及复制或截取的原图一律先存系统临时目录，不提前写入工作区；仅在用户确认落盘该卡时，按 [archiving.md](archiving.md) 存入笔记目录 `assets/`。
2. **微件内联展示**：宿主支持 `<Artifact Directory>` 与 `<agent-embed>` 内联微件时，必须走内联微件展示，不改贴本地 `file:///` 链接替代。先用宿主文件创建工具建 `<Artifact Directory>/卡XX_plot.html` 空壳并设 `ArtifactMetadata: { UserFacing: true, RequestFeedback: false }`，再由绘图脚本传 `html_path` 或 `check_svg.py ... --html ...` 填入完整透明底网页，紧贴首次看图段下方用 `<agent-embed src="file:///<artifact_path>/卡XX_plot.html"></agent-embed>` 展示。复制或截取的位图原图同样转为内联图片写入透明底网页展示。
3. **无微件回退**：其余宿主回退标准 Markdown 图片引用 `` `![图注](路径)` ``。
