# 伴学绘图施工与内联展示细则

由主干 [SKILL.md](../SKILL.md) 在需要新画 `.svg` 配图或搬运原件图示时按需加载；常规纯文字推演卡不读本文件。

---

## 一、配图来源、落点与排版底线

- **原件已有清晰图示**：现成独立图片直接复制一份，不挪动原件；嵌在整页或 PDF 中的清晰图能干净裁出就截取并裁掉图外原书图注行；截不出或清晰度不足，或仅是简单框图与曲线且图内夹杂杂乱旧编号与水印时，按原图逻辑与结构用 `.svg` 重画。
- **曲线、谱图、热力图、几何矢量与公式框图**：曲线、谱图、热力图、几何矢量，以及内含分式、导数、积分、求和、矩阵元、转置或多重上下标的结构与流向框图，均走 Python `plot_helper.py` 导出精简 `.svg`。
- **纯文字与简单符号框图**：以中文、代码短词、箭头及零星单个字母、简单下标或维度标记为主的流程、状态、时序与维度框图，直接手写 `<svg>` 并经 `check_svg.py` 过检后展示。
- **临时落点与图内底线**：讲卡展示、靶向直答与纯会话伴读期间，新画 `.svg` 及复制或截取的原图一律先存系统临时目录，不提前写入工作区。曲线名、方向箭头与关键数值直接标在线或箭头旁，说明框放空白角不压线，少用孤立图例框；单图主色不超 `3` 种，同卡多图同一量固定同色，图内正负号与字母跟正文算式一致。

---

## 二、Python 绘图施工清单

1. **读顶部速查**：只读 `scripts/plot_helper.py` 顶部速查注释；画公式框图优先横向展开或压在 `2~3` 层内，框内只放关键式子与短标签，冗长推导留正文；未覆盖新图型直接用返回的原生 `fig, ax` 自由绘制，伴学期间不改公共脚本。
2. **临时脚本与按需出表**：绘图临时 `.py` 写进系统临时目录，不在工作区留脚本。看形状趋势的图直接在图上标清关键点，正文不强制附数值小表；仅当正文确需读准数值做对比时，才在同一脚本里顺手 `print` 出特征点填表，保证表图一致。
3. **运行导出图形**：用 `uv run --project "<本技能目录>/scripts" "<系统临时目录>/plot_xx.py"` 导出精简 `.svg`；需内联展示时先按第四节建好空微件网页文件，再传 `html_path` 参数一并写入透明底网页，缺 `uv` 时提示用户先装环境。
4. **看终端与失败熔断**：终端打印碰撞、图例或配色提示时调坐标或精简文案重跑，默认不读图检查；脚本报错或体检碰撞连续修 `2` 次仍未过时立即停手，改拆简图、改用数表或交用户定夺。

---

## 三、手写 SVG 施工清单

1. **规范手写源码**：手写 `<svg>` 须写全 4 数值 `viewBox`，源码首行自带柔和浅底圆角 `<rect>` 如 `#f4f6f8`，配浅色高亮、黑体字与带箭头连线；等价对象保持同线型，虚线只作边界或辅助；图内文字不写裸 LaTeX 源码。
2. **全量跑快检与熔断**：所有手写 `<svg>` 画完均跑 `check_svg.py` 过检。优先用 `python` 或 `python3` 运行 `"<本技能目录>/scripts/check_svg.py" "<图路径>"`，无系统 Python 时用 `uv run --project "<本技能目录>/scripts" python ...` 兜底；需内联网页时先按第四节建好空微件网页文件再附加 `--html "<网页路径>"`，未过检按提示修完再展示，连修 `2` 次仍未过同样停手熔断。

---

## 四、跨宿主内联展示与延迟入库

1. **微件内联展示**：宿主支持 `<Artifact Directory>` 与 `<agent-embed>` 内联微件时，必须走内联微件展示，不改贴本地 `file:///` 链接替代。先用宿主文件创建工具建 `<Artifact Directory>/卡XX_图名.html` 空文件并设 `ArtifactMetadata: { UserFacing: true, RequestFeedback: false }`，同卡多图按图名区分，靶向直答省去卡号，再由绘图脚本传 `html_path` 或 `check_svg.py ... --html ...` 填入完整透明底网页，紧贴首次看图段下方用 `<agent-embed src="file:///<artifact_path>/卡XX_图名.html"></agent-embed>` 展示。复制或截取的位图原图同样转为内联图片写入透明底网页展示。
2. **无微件回退**：其余宿主回退标准 Markdown 图片引用 `` `![图注](路径)` ``。
3. **确认落盘入库**：仅在用户确认落盘该卡时，按 [archiving.md](archiving.md) 将临时区配图存入笔记目录 `assets/`。
