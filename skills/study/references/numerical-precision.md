# 草稿纸表征形态：数值离散、步长稳定与有限精度

适用于处理浮点舍入误差、低精度数值训练、微分方程网格推进稳定性及病态线性系统的伴学卡片。供伴学第三步做玩具浮点手算、核对步长与稳定性、画误差曲线与极值探底时按需取用。

## 1. 三位尾数截断与三点网格选数

- **三位尾数截断**：确需举算例且涉及浮点精度、低位宽格式如 `FP16` 或病态消元时，改用只保留 `3` 位有效十进制数字的玩具浮点数，每算完一步当场四舍五入，直观算清大数吞没小数有效位与相近数相减丢位。
- **三点网格选数**：涉及时间推进或空间差分时，压到 `3` 个相邻网格点手算 `2` 个时间步，先后代入小于与越过临界值的两组步长对比变化。

## 2. 抵消改写、步长权衡与稳定域核对

- **消除相减抵消**：遇到两相近数相减如 $\sqrt{x^2+1}-x$ 或单遍方差公式，先拿三位尾数算出前几位抵消归零后的粗糙结果，再做分子有理化或先减均值等价改写；遇到指数连加如 `Softmax` 或 `Log-Sum-Exp`，先提出最大值 $m=\max_i z_i$ 令指数项全部小于等于 `0` 再算。
- **截断与舍入权衡**：数值求导或积分把步长 $h$ 往小缩时，并列写出两类反向变化的误差：省掉高阶泰勒项的截断误差随 $h$ 缩小而减小，分子相减除 $h$ 放大的舍入误差随 $1/h$ 增大而急剧上升。
- **放大率与病态**：显式时间推进代入网格最高频锯齿波 $(-1)^j$，算出单步幅值放大倍数 $|G|$，核对 $|G| \le 1$ 才不发散。线性方程组求解时，分开核对矩阵本身两列近乎共线的输入敏感度，与消元未选大主元放大舍入误差的算法不稳。

## 3. 双对数误差曲线与网格依赖配图

- **双对数误差图**：步长寻优与精度权衡跑 `Matplotlib` 画双对数轴误差曲线，标亮左侧舍入误差爬升支、右侧截断误差下降支及谷底最优步长。
- **网格与锯齿图**：显式差分推进画时空网格节点连线图对比数值依赖域与真实波速锥，或并列画出稳定步长平滑曲线与跨过临界步长后的正负交替锯齿发散。

## 4. 越界步长与上下溢探底

- 紧扣成立前提探底时，优先把时间步长略微超过临界值观察正负交替振荡发散，代入极大正负数如 `±1000` 核对低精度指数上溢变 `NaN` 与下溢归零，并给近共线小矩阵右端加 `0.01` 微扰观察解的剧烈跳变。
