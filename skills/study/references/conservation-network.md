# 草稿纸表征形态：守恒控制体与等效网络

适用于处理电路与阻抗网络、热流与流体传递、力学控制体通量平衡及反馈控制框图的伴学卡片。供伴学第三步选非对称网络、列守恒账本、画切面框图与极值探底时按需取用。

## 1. 不等阻值网络与单微元选数

- 电路、热阻或管网选各支路参数互不相等的最小分岔或桥式结构，如 `2 Ω`、`3 Ω`、`6 Ω`，避开全等对称支路掩盖分流与负载耦合；连续输运先取一维单段微元 $\Delta x$ 试算进出差值。

## 2. 等势缩并、控制体账本与耦合切分

- **同色缩并节点**：动笔先把中间无元件相连的整片折弯导线、等温面或等压腔涂成同一种颜色缩并为一个节点，标出各独立节点的未知势值如电位、温度、压力，再列节点进出通量总和。求含受控源网络的等效阻抗时，只把独立源置零，保留受控源并在端口外加 `1 V` 或 `1 A` 测试源算比值。
- **隔离与直连**：级联模块先看接口性质：有理想缓冲隔离或纯信号采样时，按单向箭头框图逐块相乘，并照抄求和点实标的 `+ / -` 号写出差值式；无隔离物理直连时，把前后级并入同一守恒节点重算分流与分压。闭环路径无积分器或储能元件隔开时，直接列瞬时方程 $y=f(y)$ 联立求解。
- **控制体速率账**：用闭合虚线框圈定空间固定控制体，把所有进出项统一折算为单位时间的速率量如 `[W]`、`[kg/s]`、`[A]`，按 `流入率 - 流出率 + 框内生成率 = 框内累积变化率` 对账。图上先锁死唯一坐标正方向与支路参考箭头，直接代本构式让梯度符号与公式负号自动相乘，算出负数只表示实际流向与参考箭头相反。

## 3. 控制体切面与拓扑框图配图

- **虚线框法向图**：热流、流体与连续守恒跑 `Matplotlib` 或手写 `<svg>` 画出闭合虚线控制体切面，在边界面垂直向外标出法向箭头与进出速率符号。
- **拓扑与信号图**：等效网络与控制流手写白底圆角 `<svg>` 框图，同势导线同色高亮，物理双向耦合画无箭头或双向支路，控制信号流画单向箭头并在求和圆圈旁实标 `+ / -`。

## 4. 稳态断路与翻转坐标探底

- 紧扣成立前提探底时，优先代入稳态 $\mathrm{d}/\mathrm{d}t = 0$、端口开路零电流与短路零电压、绝热壁零通量试算，并把坐标正方向从 $+x$ 翻为 $-x$ 核对物理实际流向保持不变。
