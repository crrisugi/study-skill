# 草稿纸表征形态：空间几何与坐标系变换

适用于处理二维或三维几何向量、光线与场矢空间追迹、点乘投影、叉乘力矩、刚体旋转变换矩阵及柱球曲线坐标系的伴学卡片。供伴学第三步选最小算例、摊开坐标与投影关系、画对口配图与极值探底时按需取用。

## 1. 整数模长非对称选数

- 确需举算例时，选各分量不全相等且模长为整数的小向量手算，如二维 `(3, 4)`、三维 `(3, 0, 4)` 或 `(1, 2, 2)`；不取沿坐标轴的单位向量，也不取 `45°` 等腰巧合角。

## 2. 投影叉乘与坐标变换核对

- **投影正交分解**：算向量投影时，先算带正负号的标量投影 $c = \mathbf{a}\cdot\hat{\mathbf{b}}$，再乘单位方向得矢量投影 $\mathbf{a}_\parallel = c\hat{\mathbf{b}}$；紧接着写出垂直分量 $\mathbf{a}_\perp = \mathbf{a} - \mathbf{a}_\parallel$，验算点乘为 `0` 且首尾相加还原 $\mathbf{a}$。叉乘按右手系行列式展开核对正负号。
- **转向量与转轴**：遇到旋转或刚体变换矩阵，首行先点明矩阵是“在同一坐标系下把向量转走”，还是“向量不动、换到转过的新坐标轴下读分量”；两套矩阵互为逆矩阵，多步连乘时标明绕固定轴还是随动轴的先后次序。
- **曲线坐标微元**：切入极坐标、柱坐标或球坐标求导积分时，先标出局部单位基矢随角度转动的变化，再写全弧长、面积或体积微元里的半径与正弦缩放因子，如 $r\,\mathrm{d}r\,\mathrm{d}\theta$。

## 3. 二维主截面与三维落垂线配图

- **先切二维截面**：能在一个平面内看清夹角、折射或投影时，先切出该二维主截面，调用底座二维箭头图元标清角度与垂足直角号。
- **三维垂线落影**：确需展示三维空间方位时，调用底座三维落影图元，从向量终点向底面落竖直虚线并与原点连成底面投影直角三角形，偏开视角避开坐标轴遮挡。

## 4. 极端角度探底

- 紧扣成立前提探底时，优先代入夹角大于 `90°` 的钝角向量核对点乘变负反向，代入共线向量核对叉乘归零，再拿单个坐标基矢转 `90°` 核对变换矩阵的正负号。
