# 草稿纸表征形态：量词顺序、充要条件与反例证明

适用于处理数理逻辑量词、充要条件辨析、数学归纳法、实分析与代数定理证明及组合计数双射的伴学卡片。供伴学第三步选极简集合、搭推演骨架、画包含箭头与构造最小反例时按需取用。

## 1. 极简有限集与多算一步基例

- **有限集穷举**：验证抽象命题或组合计数时，压到 `2~3` 个元素的有限集合或两段折线列小表穷举真实结果；组合计数把分步乘法生成的序列逐一对回结果表，数清每个结果被重算了几遍再除掉重数。
- **归纳多算一步**：数学归纳法算完起始点 $n_0$ 后，多手算一步 $n_0 \to n_0 + 1$ 的具体过渡，核对小规模下相邻两步的交集或递推桥梁是否真能接上。

## 2. 量词依赖、证明骨架与前提对账

- **标明量词依赖**：对比 $\forall x\,\exists y$ 与 $\exists y\,\forall x$ 时，把后出场的存在量写成带括号的 $y(x)$ 标明它允许随 $x$ 换值，与全局固定常值 $y_0$ 并排对照。对多层量词命题取反时，从左往右逐个翻转 $\forall \leftrightarrow \exists$，直到把否定号推入最里层条件。
- **先搭单向骨架**：动笔首行写明推演路线：直接证写 `已知 P ⟹ 目标 Q`，逆否证写 `假设 ¬Q ⟹ 目标 ¬P`，反证法写 `同设 P 与 ¬Q ⟹ 推矛盾`。在草稿纸上从目标倒推算出的界如 $\delta(\epsilon)$，正推时调头从已知条件出发顺写单向链，不把必要条件当充分条件逆用。
- **归纳与标前提**：写归纳步时上下分成两行，上行锁死固定 $k$ 的已知式 $P(k)$，下行把待求的 $P(k+1)$ 左端硬拆出 $P(k)$ 那一团整体代换。长证明跨关键变形步时，在等号或不等号旁用短词标出这步用掉了哪条前提，如闭区间、单调、非零或互素。

## 3. 蕴含箭头与双射连线配图

- **蕴含与包含图**：辨析充分、必要与充要条件时，手写白底圆角 `<svg>` 画出单向或双向箭头及嵌套集合包含圈，标明哪一侧范围更窄。
- **双射与反例图**：组合双射构造在左右两列各摆 `3~4` 个具体对象画一一连线核对可逆；分析证明涉及连续或界限时，跑 `Matplotlib` 画出挖空单点或带跳变折角的极简反例曲线。

## 4. 逐一删前提构造反例探底

- 紧扣成立前提探底时，每次只删掉定理中的 `1` 个前提如把闭区间 `[0, 1]` 改成开区间 `(0, 1)` 或去掉互素条件，用 `2~3` 个数字或分段小函数构造最小反例，精准标出原证明在哪一行卡住失效。
