# 草稿纸表征形态：高维数组与变换求导

适用于处理矩阵代数与特征分解、基底线性映射、多维张量重排与掩码、神经网络层及反向传播求导的伴学卡片。供伴学第三步选非对称小数组、摊开维度与求导链、画基底落点或热力配图与极值探底时按需取用。

## 1. 非对称小整数块与保序拆解

- **非方阵选数**：确需举算例时，把批大小、序列长与特征维压到 `2×3` 或 `2×2`，填入非对称小整数如 `[1, 2, -1; 0, -1, 3]` 亲手算通，不用全 `1` 或对称阵。看矩阵几何作用时，顺手代入标准基 $e_1=[1,0]^\top$、$e_2=[0,1]^\top$，直接读出变换后落点就是矩阵各列。
- **保序拆开连乘**：遇到多层矩阵连乘变形，锁死左右相乘次序逐项拆括号，不把 $AB$ 与 $BA$ 合并；或直接按下标写成求和式 $\sum_k A_{ik}B_{kj}$ 核对。

## 2. 维度缩并链与内存掩码核对

- **写全维度缩并**：每步运算写明维度 `Shape` 变化链，如 `[2×3] · [3×4] → [2×4]`；遇到两向量相乘，写明是行乘列 `[1×n] · [n×1] → [1×1]` 缩成标量内积，还是列乘行 `[n×1] · [1×n] → [n×n]` 张成外积矩阵。广播运算把两张量的 `Shape` 靠右对齐、左侧缺维补 `1`，标明哪一轴被复制放大。
- **重排与掩码**：遇到 `Reshape` 与 `Permute` 或 `Transpose`，先把 `2×3` 数组按行写成一维连续序列，对照“按顺序重切分块”与“行列下标互换”后元素各落在哪一格。遇到掩码 `Mask`，分清逐元素相乘填 `0` 清零，还是指数归一化前填 `-∞` 令归一后权重变 `0`，并标明沿哪一维求和归一。
- **求导同形归并**：算反向传播梯度 $\partial L / \partial X$ 时，先在非对称小矩阵上改单个元素看它沿链式法则乘了谁，再按“梯度与原变量同 `Shape`”核对转置放左还是放右；前向被广播复制过的参数，反向梯度沿该复制轴累加求和压回原形状，复数域同步核对共轭。

## 3. 几何落点、维度框图与热力图

- **基矢落点配图**：涉及基底拉伸剪切、特征向量或奇异值分解时，调用底座二维箭头图元画出标准基或单位圆小方格变换前后的落点，直接对回矩阵列数值与拉伸方向。
- **框图与热力图**：多步张量流转手写圆角 `<svg>` 框图并在连线标 `Shape`。权重、注意力或损失分布跑 `Matplotlib` 画热力图并在关键格内直接标值：含正负值用零值留白的红蓝双色盘，`-∞` 屏蔽格打灰斜纹与零值格区分。

## 4. 退化值与计算量探底

- 紧扣成立前提探底时，优先代入两列成比例的奇异阵、全零或极大差值核对不可逆、除零及权重硬饱和与梯度归零，并按真实维度对比乘法次数与显存量级，如 $O(N^3)$ 与 $O(N^2)$。
